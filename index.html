🔐 Fingerprint Enrollment Guide

Fingerprints are enrolled directly on the R307 sensor via ESP32. Follow these steps:

1

Add User to Database

First, add the user in the "Users" tab with their name, department, and assign a unique fingerprint ID (e.g., 1, 2, 3...).

2

Upload ESP32 Enrollment Code

Use the enrollment sketch on your ESP32 to register fingerprints on the R307 sensor. The fingerprint ID in the sensor should match the one in the database.

3

Scan Fingerprint

Place the finger on the R307 sensor when prompted. The sensor will capture and store the fingerprint template with the assigned ID.

4

Test Recognition

After enrollment, test by scanning the fingerprint. The ESP32 should send attendance data to Firebase when recognized.
